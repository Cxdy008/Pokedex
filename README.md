# Pokedex

Pokedex é um projeto do Boot.dev da trilha de backend.

Este repositório foi criado para praticar e demonstrar conceitos de desenvolvimento backend usando TypeScript, com foco em construir uma aplicação de pokédex funcional e organizada.

## Tecnologias

- TypeScript

## Objetivo

Servir como um projeto de estudo e aprendizado, com foco em lógica de aplicação, estrutura de código e desenvolvimento de APIs/serviços.
